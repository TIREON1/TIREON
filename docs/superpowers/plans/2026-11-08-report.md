# 리포트 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 연습 세션 결과를 저장하고, 리포트 화면에서 기록 목록과 상세를 보여준다.

**Architecture:** `:core`에 저장 인터페이스와 도메인 모델을 두고, `:app`이 JSON 파일 구현을 제공합니다. 화면은 목록과 상세 두 단계로 나누고, 홈 점수도 저장된 최신 세션에서 가져옵니다.

**Tech Stack:** kotlinx.serialization, DataStore 없이 파일 기반 JSON, Compose

**Spec:** `docs/design/app-foundation-design.md` (6.5 저장, 4.1 내비게이션)

## Global Constraints

- 저장 형식은 JSON입니다. 스키마 버전을 남겨 나중에 마이그레이션할 수 있게 합니다.
- 측정 불가는 `null`로 저장합니다. 0으로 저장하지 않습니다.
- 저장 실패를 조용히 삼키지 않습니다. 화면에 저장 실패를 알립니다.
- 개인정보를 저장하지 않습니다. 좌표, 위치, 사용자 식별자를 넣지 않습니다.
- 커밋 메시지는 `type: 한국어 내용` 형식을 따릅니다.
- 검증 명령: `./gradlew assembleDebug test lint`

## Review Focus

1. 저장 파일이 깨졌을 때. 앱이 죽지 않고 빈 목록으로 시작해야 합니다.
2. 저장 공간이 부족할 때. 저장 실패가 사용자에게 보여야 합니다.
3. 세션 수가 많아질 때. 목록이 느려지지 않아야 합니다.
4. 스키마가 바뀔 때. 이전 파일을 읽을 수 있어야 합니다.
5. 홈 점수가 오래된 세션을 보여주는 경우. 최신 세션 기준이어야 합니다.

package ai.tireon.core.report

import ai.tireon.core.DrivingScore
import ai.tireon.core.analysis.InsufficientReason
import ai.tireon.core.analysis.ScoreResult
import ai.tireon.core.driving.Confidence
import ai.tireon.core.driving.DrivingEvent
import ai.tireon.core.driving.DrivingEventType
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertNull

class SessionRecordFactoryTest {

        type = type,
        atMs = 0L,
        value = 3f,
        confidence = Confidence.MEASURED,
    )

    @Test
    fun `점수가 있으면 기록에 숫자를 담는다`() {
        val record = SessionRecordFactory.create(
            id = "s1",
            startedAtMs = 1_000L,
            durationSec = 120,
            distanceKm = 1.5f,
            result = ScoreResult.Scored(DrivingScore(88), emptyList()),
            events = listOf(event(DrivingEventType.HARSH_BRAKE)),
        )

        assertEquals(88, record.score)
        assertNull(record.insufficientReason)
        assertEquals(1, record.eventCounts["HARSH_BRAKE"])
        assertEquals(1, record.schemaVersion)
    }

    @Test
    fun `데이터 부족은 점수 없이 사유를 남긴다`() {
        val record = SessionRecordFactory.create(
            id = "s2",
            startedAtMs = 2_000L,
            durationSec = 10,
            distanceKm = null,
            result = ScoreResult.Insufficient(InsufficientReason.DURATION_TOO_SHORT),
            events = emptyList(),
        )

        assertNull(record.score)
        assertEquals("DURATION_TOO_SHORT", record.insufficientReason)
        assertNull(record.distanceKm)
    }

    @Test
    fun `이벤트가 없으면 빈 맵이다`() {
        val record = SessionRecordFactory.create(
            id = "s3",
            startedAtMs = 3_000L,
            durationSec = 60,
            distanceKm = 1f,
            result = ScoreResult.Scored(DrivingScore(100), emptyList()),
            events = emptyList(),
        )

        assertEquals(emptyMap(), record.eventCounts)
    }
}

- [ ] **Step 1: 테스트를 쓴다 (실패 예정)**

테스트는 `java.io.tmpdir` 아래 임시 디렉터리를 씁니다. Android 의존이 없어 JVM에서 돌아갑니다.

```kotlin
package ai.tireon.app.report

import ai.tireon.core.report.DrivingSessionRecord
import kotlinx.coroutines.test.runTest
import org.junit.Rule
import org.junit.rules.TemporaryFolder
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertNull
import kotlin.test.assertTrue

class FileSessionRepositoryTest {

    @get:Rule
    val folder = TemporaryFolder()

    private fun record(id: String, startedAtMs: Long, score: Int? = 80) = DrivingSessionRecord(
        id = id,
        startedAtMs = startedAtMs,
        durationSec = 60,
        distanceKm = 1f,
        score = score,
        insufficientReason = if (score == null) "DURATION_TOO_SHORT" else null,
        eventCounts = emptyMap(),
    )

    @Test
    fun `저장한 기록을 다시 읽는다`() = runTest {
        val repository = FileSessionRepository(folder.root)

        val saved = repository.save(record("a", 1_000L))
        val latest = repository.latest()

        assertTrue(saved.isSuccess)
        assertEquals("a", latest?.id)
    }

    @Test
    fun `최근 기록은 최신 순으로 정렬된다`() = runTest {
        val repository = FileSessionRepository(folder.root)
        repository.save(record("old", 1_000L))
        repository.save(record("new", 5_000L))

        val recent = repository.recent(limit = 10)

        assertEquals("new", recent.first().id)
        assertEquals("old", recent.last().id)
    }

    @Test
    fun `기록이 없으면 빈 목록이다`() = runTest {
        val repository = FileSessionRepository(folder.root)

        assertTrue(repository.recent(10).isEmpty())
        assertNull(repository.latest())
    }

    @Test
    fun `깨진 파일은 무시하고 빈 목록을 준다`() = runTest {
        val file = folder.newFile("sessions.json")
        file.writeText("{ broken json")

        val repository = FileSessionRepository(folder.root)

        assertTrue(repository.recent(10).isEmpty())
    }

    @Test
    fun `저장 개수 제한을 넘으면 오래된 기록을 버린다`() = runTest {
        val repository = FileSessionRepository(folder.root, maxRecords = 3)
        repeat(5) { index -> repository.save(record("s$index", index * 1_000L)) }

        val recent = repository.recent(limit = 10)

        assertEquals(3, recent.size)
        assertEquals("s4", recent.first().id)
    }
}
```

`kotlinx-coroutines-test` 의존성을 `:app`에 추가합니다.

- [ ] **Step 2: 실패를 확인한다**

Run: `./gradlew :app:testDebugUnitTest --tests '*FileSessionRepositoryTest*'`
Expected: FAIL

- [ ] **Step 3: 구현한다**

단일 JSON 파일에 목록을 저장합니다. 읽을 때 파싱에 실패하면 빈 목록을 반환하고 로그를 남깁니다. 저장 시 `startedAtMs` 내림차순으로 정렬하고 `maxRecords`를 넘으면 오래된 것을 버립니다. 쓰기는 임시 파일에 한 뒤 이름을 바꿔 중간 실패로 파일이 깨지지 않게 합니다.

- [ ] **Step 4: 통과를 확인한다**

Expected: PASS (5 tests)
